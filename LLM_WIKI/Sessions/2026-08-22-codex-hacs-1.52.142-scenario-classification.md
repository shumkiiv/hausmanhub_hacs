# Сессия: HACS 1.52.142, классификация сценариев

Дата: 2026-08-22
Агент: Codex

## Решения

- Классификация сценария принадлежит backend и публикуется через scenario
  list v1. Клиенты не должны вычислять тип по локальным эвристикам.
- Системная защита является серверной политикой: delete возвращает conflict,
  update не может снять системную группу у существующего protected-сценария.
- Изменение обратно совместимо для Android 1.0.242 и текущего HACS frontend.
  UI baseline сохранён.

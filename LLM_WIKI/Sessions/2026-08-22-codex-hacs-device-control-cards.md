# HACS: карточки управления устройствами

Дата: 2026-08-22

Агент: Codex

## Решения

- Изменён только HACS frontend. Android, backend, API, contracts и storage не
  затрагивались.
- Управление физическими устройствами вынесено в общий модуль
  `hausman-hub-device-controls.js` и связанные стили.
- Карточки строятся по возможностям сущностей: состояние, одно актуальное
  действие и компактные диапазоны без повторяющихся технических данных.
- Переименование каналов доступно администратору и записывается напрямую в
  реестр сущностей Home Assistant через `config/entity_registry/update`.
  Локальная копия имени в HACS не создаётся.

# Связи питания устройств, HACS 1.52.169

- Дата: 2026-08-26
- Агент: Codex
- Репозиторий: `components/integration`
- Ветка: `codex/device-command-links-2026-08-26`

## Решение

Связь сделана направленной предпосылкой питания, а не зеркалированием
состояний. Для политики `auto_turn_on` Hausman Hub включает источник,
подтверждает состояние, ждёт от 0 до 30 секунд и только после этого отправляет
исходную команду. Источник автоматически не выключается.

Старая политика `requires_on` продолжает только блокировать команды при
выключенном источнике. Недоступный источник в обоих режимах закрывает команду
безопасно. Циклы и несколько источников для одной сущности запрещены.

## Реализация

- Contracts `0.59.0`, commit `5189a020c395babb65795b17f35674b31c4c0a45`.
- HACS version `1.52.169`.
- Прямые действия и сценарии проходят через одну подготовку питания.
- Параллельное включение одного источника защищено lock.
- Полный сброс удаляет сохранённые связи.
- В HACS добавлен экран `Настройки -> Связи питания`.

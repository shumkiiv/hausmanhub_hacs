HausmanHub

Дом, который понимает. Планшетная панель управления домом для Home Assistant: главная, комнаты, климат, освещение, энергия, сценарии, события и безопасность.

Все данные дома остаются в вашем Home Assistant. Внешнего облака HausmanHub не существует.

Эта страница является официальным веб-адресом приложения HausmanHub для авторизации Home Assistant (OAuth 2 / IndieAuth). После входа Home Assistant возвращает вас в приложение по адресу hausmanhub://auth-callback.

Интеграция для Home Assistant: hausmanhub_hacs.

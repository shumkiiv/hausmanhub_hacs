# Release audit HausmanHub 1.52.89

Дата: 2026-08-13.

## Область выпуска

- Добавлены русские подписи для всех числовых настроек, которые остались на
  английском в рабочем Dashboard API после выпуска 1.52.88.
- Диапазоны, серверная проверка границ и шага, opaque target и действие
  `set_value` не менялись относительно 1.52.88.
- Интерфейс HACS не менялся. Версии frontend-ресурсов обновлены только для
  согласованного release cache busting.

## Проверка до публикации

- Профильный тест снимка Dashboard API пройден.
- Полный backend-набор: 1381 тест пройден, 4 пропущено.
- `tools/check_local_release.py`: fixtures, Android compatibility, HACS package,
  naming и проверки безопасности зелёные.
- Физические команды устройствам не отправлялись.

## После публикации

- Release commit `eba7c8a`, tag `v1.52.89` и GitHub Release опубликованы.
- GitHub Actions `31732638754` завершён успешно.
- Использован полный backup `3b21195e`, созданный непосредственно перед
  установкой `1.52.88`; дополнительные изменения между выпусками затрагивали
  только перевод подписей и cache version.
- Production прошёл `homeassistant.check_config`, установку и перезапуск.
  Installed, latest и marker панели равны `1.52.89`.
- Live Dashboard API вернул 13 комнат, 79 доступных на момент проверки
  устройств и 37 диапазонов. Все границы и шаги валидны, target остаётся
  непрозрачным, действие равно `set_value`, все 19 типов диапазонов подписаны
  по-русски.
- В системном журнале Home Assistant нет записей HausmanHub после перезапуска.
- Физические команды устройствам не отправлялись.

# Release audit HausmanHub 1.52.89

Дата: 2026-08-13.

## Область выпуска

- Добавлены русские подписи для всех числовых настроек, которые остались на
  английском в рабочем Dashboard API после выпуска 1.52.88.
- Диапазоны, серверная проверка границ и шага, opaque target и действие
  `set_value` не менялись относительно 1.52.88.
- Интерфейс HACS не менялся. Версии frontend-ресурсов обновлены только для
  согласованного release cache busting.

## Проверка до публикации

- Профильный тест снимка Dashboard API пройден.
- Полный backend-набор: 1381 тест пройден, 4 пропущено.
- `tools/check_local_release.py`: fixtures, Android compatibility, HACS package,
  naming и проверки безопасности зелёные.
- Результаты рабочего деплоя будут записаны после завершения проверки.
- Физические команды устройствам не отправлялись.

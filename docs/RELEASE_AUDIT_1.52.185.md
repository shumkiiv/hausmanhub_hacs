- Выбранные данные managed Node-RED-алгоритма теперь отображаются отдельным
  понятным списком над системным выбором.
- Пользователь видит количество выбранных значений, устройство, комнату или
  свойство, может удалить одну строку либо очистить весь набор.
- Временно отсутствующее в каталоге выбранное значение не теряется и явно
  помечается как недоступное.
- Commit, annotated tag `v1.52.185` и Release без assets указывают на
  `1678ee8`.
- GitHub Actions `33077543877` завершился успешно.
- Production Home Assistant использует installed/latest `v1.52.185`.

- installed/latest равны `v1.52.185`, обновление не выполняется.
- В каталоге 53 сценария, все 53 включены; Scenario Health `healthy`.
- Node-RED 22.0.2 установлен, запущен и подключён; доступны два managed flow.
- Live JS и CSS отдаются с HTTP 200. В JS присутствуют новый счётчик, очистка,

  дому не отправлялись.

  перезапуска Home Assistant оставалась недоступна; остальные девять служебных
  сенсоров Hausman были доступны. Это не затрагивает редактор и сценарии.

## Откат

`v1.52.184`, выполнить config check и один restart.

# Недостающий контракт настроек интерфейса

Экран HACS уже применяет тему, уменьшение анимации и показ подсказок в текущей
сессии. Существующий `connection-settings` сохраняет только параметры связи,
поэтому после полного перезапуска браузера интерфейсные предпочтения восстановить
неоткуда.

Для постоянного хранения без изменения frontend-контракта подключения нужен
отдельный локальный admin API:

- `GET hausman_hub/v1/admin/panel-preferences`;
- `POST hausman_hub/v1/admin/panel-preferences`.

Тело и ответ:

```json
{
  "theme": "auto",
  "reduced_motion": false,
  "show_hints": true
}
```

Ограничения:

- `theme`: только `auto`, `light` или `dark`;
- оба остальных поля обязательны и имеют тип boolean;
- маршрут доступен только локальному администратору Home Assistant;
- запись не запускает устройства и не влияет на климатический контур;
- хранение версионированное, отдельно от секретов и параметров подключения.

До появления этого API панель не сообщает о долговременном сохранении этих трёх
настроек: они действуют только до перезагрузки страницы.

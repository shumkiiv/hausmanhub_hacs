# Энергия в HausmanHub

Версия 1.47.3 добавляет единое представление энергии для панели Home Assistant
и планшетного приложения. Источник истины — Home Assistant: настройка сохраняется
локальным администраторским API и включается в dashboard snapshot.

## Что считается одним источником

Одна карточка соответствует одному физическому устройству из device registry,
даже если оно публикует отдельные сущности мощности, тока, напряжения и энергии.
Показания приводятся к `Вт`, `А`, `В` и `кВт·ч`. Мощность и накопленная энергия
не смешиваются: мощность показывает текущую нагрузку, энергия — показание
накопительного счётчика.

При ручном выборе нельзя одновременно учитывать общий счётчик и все его
дочерние розетки: их сумма будет двойным учётом. Для разных фаз и линий режим
«Вместе» суммирует мощность и ток, а напряжение показывает среднее доступное
значение. Сумма токов имеет физический смысл только для источников одной линии.
Поэтому после установки автоматический выбор выключен: администратор сначала
выбирает корректный уровень учёта, а затем при желании включает все источники.

## API настройки

`GET /api/hausman_hub/v1/admin/energy-settings` возвращает сохранённую настройку.
`POST` принимает документ по `contracts/v1/energy-settings.schema.json`:

- `displayUnits`: `watts`, `amps` или `both`;
- `showVoltage`: показывать текущее напряжение;
- `aggregation`: `combined` или `separate`;
- `useAllDevices`: автоматически включать все подходящие физические устройства;
- `selectedDeviceIds`: ручной список непрозрачных публичных ID.

Endpoint доступен только локальному администратору, не раскрывает `entity_id` и
не отправляет команды устройствам. Быстрое управление на странице использует
только ранее разрешённые действия каталога с существующей проверкой результата.

## Графики

Панель HA запрашивает часовую статистику мощности за последние 24 часа через
Recorder. Если статистики нет, интерфейс честно показывает текущее значение без
рисования вымышленных данных. Dashboard snapshot объявляет историю отдельной
возможностью; для внешних клиентов она останется выключенной до появления
типизированного read-only endpoint истории.

# Hausman Hub HACS 1.52.221: запуск smart switch на Home Assistant 2026.9

Дата подготовки: 2026-09-05.

## Причина выпуска

Home Assistant 2026.9 обращается к служебной информации обработчика как к
полной структуре `TriggerInfo`. Старый объект с внутренним полем `source`
вызывал `KeyError` при запуске интеграции.

## Исправление

- Прикрепление получает только фиксированный `TriggerInfo`: `domain`, `name`,
  `variables` и `trigger_data` с `id`, `idx`, `alias`.
- Callback принимает стандартные `run_variables` и необязательный `context`,
  но не использует их для выбора устройства или действия.
- Частичный запуск очищает только уже созданные callbacks, а успешное и
  повторное завершение очищают каждый callback один раз. После unload старые
  callbacks неактивны.

## Проверки и границы

- Добавлена boundary-проверка со строгой заглушкой HA 2026.9.
- Профильный набор smart switch: 62 теста.
- Физические команды, вода, автоматы и deploy не выполнялись.

# Release audit HausmanHub 1.52.95

Дата: 2026-08-14.

## Область выпуска

- HACS `1.52.94` добавил в каталог сценариев `sun.sun` с русскими состояниями
  `До заката` и `После заката`, а свету - команду
  `Яркость по времени суток`.
- Команда вычисляет уровень по фактическим времени заката и восхода Home
  Assistant: 100% на закате, плавное снижение до указанного минимума к
  полуночи и обратный рост до 100% к восходу.
- Режим `restart` теперь действительно отменяет прежний таймер при новом
  запуске. `single` и `queued` также исполняются по контракту.
- Патч `1.52.95` учитывает включённый предыдущим шагом источник питания и не
  отклоняет команду зависимому светильнику из-за задержки обновления HA state.
  Readback включения выполняется перед длинной задержкой, выключение
  подтверждается после неё.

## Сценарий малого коридора

- Основной сценарий сохранил ID `scenario_mssvmo6v` и название
  `Свет по движению малый коридор`. Его execution mode - `restart`.
- Последовательность: включить реле, установить солнечную яркость с минимумом
  25%, ждать 300 секунд, выключить реле.
- Ночной вход запускается движением, если `sun.sun=below_horizon`.
- Дневной вход запускается движением, если солнце ещё над горизонтом и
  целочисленный уличный датчик имеет значение ниже 401 лк. Для этого датчика
  это точное представление условия `<= 400 лк`.
- Два входа взаимоисключающие, поэтому одно движение не создаёт двойной запуск.
  Они вызывают один основной сценарий, а новое движение перезапускает его
  5-минутный таймер.
- Исходный registry сохранён вне репозитория:
  `~/.config/hausmanhub/audit/20260814T174300Z-small-corridor-light/`.

- HACS `1.52.94`: 1396 тестов пройдено, 4 пропущено; GitHub Actions

- HACS `1.52.95`: 1399 тестов пройдено, 4 пропущено. Schema fixtures, Android

  прошли. GitHub Actions `31814541329` завершён успешно.

## Production

- Перед `1.52.94` automatic backup завершён в
  `2026-08-14T15:12:20+00:00`; перед `1.52.95` - в
  `2026-08-14T15:33:39+00:00`. Оба раза backup manager вернулся в `idle`.
- Config check принят до и после каждой установки, а также после restart.
  Каждый выпуск потребовал один штатный restart.
- Installed, latest и frontend cache marker равны `1.52.95`. Живой каталог
  содержит 457 сущностей и публикует адаптивную команду у люстры малого
  коридора.
- После restart первый dry-run дневного входа попал в короткое окно
  формирования каталога и вернул semantic validation error. Повторная проверка
  после стабилизации каталога прошла, оба свойства уже имели нужные сравнения.
- Финальный dry-run всех трёх определений успешен: основной план содержит
  четыре шага и задержку 300 секунд, текущая расчётная яркость была 78% при
  минимуме 25%; ночное условие прошло, дневной взаимоисключающий вход был
  корректно пропущен.

Dry-run не отправлял физических команд. Состояния реле, люстры, датчика
движения и уличного датчика после проверки не изменились.

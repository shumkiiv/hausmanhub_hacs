# Диагностика недоступности climate runtime после 1.52.235

## Итог

Климатический интерфейс планшета отключён безопасно, потому что одна
сохранённая запись общей цели не проходит строгую проверку. Нативный
климатический runtime, конфигурация интеграции, пять комнат и их реестр
доступны. Это не отказ Home Assistant и не проблема связи с приборами.

Версия `1.52.235` не меняла обработку общей цели. Она добавила только
действие возврата в автоматический режим и исправила подпись отчёта
браузерной проверки. Повторять установку или restart не нужно.

## Подтверждённая причина

Последняя надёжная запись общей цели была создана 2026-09-09 в 04:35 UTC и
завершилась через 61 секунду. Её квитанция, область действия, подписи,
checkpoint и границы повторной отправки проходят проверку. Результат имеет
пять комнат: две ветви подтверждены, одна отложена, четыре сохранены как
ручные, одна завершилась без подтверждения после принятия команды.

Внутренний журнал помечен `accepted_timeout`. Он допускает только
подтверждённые ветви и ветви с истёкшим подтверждением. Фактический набор
содержит также отложенную и ручные ветви, для него существует
`terminal_mixed`. Строгая загрузка справедливо отказывается принимать такое
несоответствие и не создаёт `ClimateTabletService`. Публичный маршрут
`/api/hausman_hub/v1/climate/runtime` вследствие этого возвращает 503
`unavailable`.

Проверка не раскрывала содержимое защищённой истории, идентификаторы
операций или ключи. Она сверила только форму записей, контрольные суммы,
подписи и счётчики классов результатов.

## Граница ремонта

Нужен отдельный узкий инкремент с воспроизводящим тестом смешанного исхода
после истечения подтверждения. Он должен переводить только достоверно
проверенную историческую запись из `accepted_timeout` в `terminal_mixed`,
сохраняя запрос, квитанцию, количество принятых команд, ручное владение и
запрет повтора. Новую команду климатическим приборам отправлять нельзя.

До такого ремонта запрещены изменения файлов хранилища вручную, повторная
общая цель, повторная установка и restart ради этой неисправности.

## Как продолжать работу

Новый или обновлённый экран сначала создаётся либо сверяется на подходящей
CANON-странице. Предыдущая версия переносится в Archive и получает префикс
`ARCHIVE /`. Реализация HACS не должна ссылаться на Archive. Список audited
node ID хранится в
[`ui-source-of-truth-audit.json`](ui-source-of-truth-audit.json).

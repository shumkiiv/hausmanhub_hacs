# Проверка выпуска 1.52.201

## Что входит

Выпуск делает поиск комнат доступным для экранных читалок и закрепляет
исчерпывающую QA-проверку за детерминированным содержимым выпуска.
Надёжная ветка климата теперь публикуется только когда сервис успешно
инициализировал внешний аутентифицированный persistent-журнал. После ошибки
сохранения эта ветка скрывается, при этом безопасное чтение климата остаётся
доступным. Контракт API и физические команды не менялись.

Recovery v2 следует тому же fail-closed правилу. Полный QA-отчёт связан с
детерминированным SHA-256 `c0ab8aa35c03d22665ef81a6f2f1544e239bba401bf6d59b50621365c0893453`
проверяемых frontend-файлов, browser harness и наблюдаемого реестра контролов.
Это доказательство можно пересчитать для подготовленного дерева и финального
выпуска.

Неполный внешний якорь не сбрасывается автоматически. После ошибки сохранения
все климатические мутации остаются закрытыми до нового запуска, а чтение
состояния сохраняется. Live helper допускает только GET/HEAD точного origin и
WebSocket той же схемы, хоста и порта.

## Обязательные финальные проверки

- полный HACS test, browser и exhaustive QA gates;
- независимые code review и security audit;
- проверка production-совместимости с Android `1.0.270` и contracts `0.64.3`;
- config check целевой базы до и после установки, затем read-only smoke.

## Safety denylist

Не выполнять команд для автоматов, кранов воды, замков, охраны, сирен,
отопления, кондиционеров, света, штор, ворот, бытовой техники или любого
другого физического устройства. Для этого выпуска разрешены только проверки
интерфейса, конфигурации и чтения состояния.

резервная копия и успешная проверка конфигурации Home Assistant.

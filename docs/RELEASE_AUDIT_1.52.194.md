# Проверка выпуска 1.52.194

## Результат

Каталог сценариев Hausman публикует для `cover` отдельное числовое свойство
`current_position` с единицей `%`. Его можно использовать в условиях
`above`, `below`, `equals` и `not_equals`, не смешивая позицию с общим
состоянием `open` или `closed`.

## Живая причина

Привод кабинета Lilistore TS0601 у нижнего механического упора сообщает 7-8%.
Повторная команда позиции 0% из высокочастотного светового сценария развернула
его на открытие. Отдельная автоматическая ветвь сможет закрывать кабинет только
при `current_position > 20`, а повторные события безопасно пропускать.

## Проверки выпуска

- каталог обычного устройства не получает лишних свойств;
- штора получает стабильные `state` и `current_position`;
- позиция числовая, использует проценты и поддерживает числовые сравнения;
- профильный набор: 276 тестов и 113 подтестов прошли;
- полный HACS release gate: 1864 теста, 4 пропущены;
- branch coverage критического runtime: 76% при пороге 75%;
- Chromium: 19 из 19 тестов прошли.

## Production

- Release `v1.52.194`, commit `bcc5f20`, GitHub Actions `33318348229` успешен.
- Точная версия `v1.52.194` установлена после config check HTTP 200 и одного
  restart. Затем production обновился до `v1.52.195`, прямого потомка этого
  выпуска, который сохраняет свойство `current_position`.
- Четыре общие ветви закрытия больше не отправляют команды кабинету. Кабинет
  покрыт тремя отдельными ветвями с теми же событиями и условием
  `current_position > 20`.
- Живой тест: первое выполнение закрыло кабинет с логических 100% до 8%,
  повторное было пропущено без квитанций, следующие 32 секунды позиция
  оставалась 8%. Общий сценарий закрыл остальные три шторы до 0% и не изменил
  положение кабинета.
- Scenario Health: `healthy`, нарушений нет.

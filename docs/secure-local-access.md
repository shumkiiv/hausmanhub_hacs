# Безопасный доступ к Home Assistant с нового компьютера

HausmanHub работает через HTTPS. Если старый адрес с `http://` не отвечает, это
не означает, что Home Assistant остановился: браузер мог обратиться к уже
отключённому небезопасному входу.

## Быстрая проверка

1. Откройте адрес вида `https://<имя-дома>:8123/config/dashboard`.
2. Ответ `401` у API без авторизации означает, что сервер доступен и защищает
   данные как положено.
3. Если браузер сообщает, что не доверяет сертификату, не выбирайте обход
   предупреждения и не отключайте HTTPS. Установите корневой сертификат дома.

## Windows: три безопасных шага

Перед началом попросите владельца дома передать именно публичный корневой
сертификат в формате `.cer` или `.crt` и его SHA-256 отпечаток отдельным
каналом. Никогда не передавайте и не импортируйте файл закрытого ключа
(`.key`, `.pem` с private key).

1. Сверьте SHA-256 файла с отпечатком от владельца. Если они различаются,
   остановитесь.
2. Дважды щёлкните файл, выберите «Установить сертификат», затем
   «Текущий пользователь» и хранилище «Доверенные корневые центры
   сертификации». Windows покажет подтверждение - прочитайте имя центра и
   подтвердите только после проверки отпечатка.
3. Полностью закройте браузер и откройте безопасный адрес снова.

Для Chrome и Edge обычно достаточно хранилища Windows. Firefox умеет доверять
сторонним корням из Windows. Если предупреждение осталось только в нём,
включите в настройках приватности пункт доверия к сторонним корневым
сертификатам Windows либо включите `security.enterprise_roots.enabled` в
`about:config`, затем перезапустите Firefox. Это не отменяет проверку
отпечатка сертификата.

## Что делает панель HausmanHub

В разделе «Система» есть карточка «Безопасный доступ с нового компьютера».
Она открывает или копирует правильный HTTPS-адрес текущего Home Assistant и
повторяет безопасные шаги. Адрес берётся из открытой панели, поэтому имя дома
и IP-адрес не записываются в исходный код или публичную документацию.

Панель намеренно не устанавливает сертификат в Windows автоматически. Браузер
и Windows должны показать пользователю, какой центр сертификации становится
доверенным. Это защита от подмены дома в локальной сети.

## Как удалить доверие при замене сертификата

Откройте `certmgr.msc`, перейдите в «Доверенные корневые центры
сертификации» - «Сертификаты», найдите старый центр по заранее сверенным имени
и отпечатку, затем удалите только его. После этого импортируйте новый
проверенный корневой сертификат. Не удаляйте другие системные центры.

## Для администратора HausmanHub

Будущий мастер может раздавать публичный корневой сертификат из панели только
после отдельной настройки источника сертификата, контроля доступа администратора
и показа SHA-256 отпечатка. До этого безопаснее передавать файл и отпечаток
владельцем дома через доверенный канал. Мастер не должен включать HTTP,
ослаблять TLS или принимать сертификат без подтверждения пользователя.

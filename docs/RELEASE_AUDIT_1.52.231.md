# Проверка Hausman for Home Assistant 1.52.231

Сохранение ручного или автоматического режима больше не требует точного
равенства времени записи и следующего чтения. Обычное обновление наблюдений
может продвинуть часы общей памяти, не меняя режим. Более новое долговечное
чтение той же настройки подтверждает результат с нулём физических команд.
Старое наблюдение или другой режим не принимаются.

Дефект воспроизведён до исправления тестом с движущимися часами. После
исправления проверены четыре вида климатических приборов, вся комната,
фоновая обработка, дубликат и загрузка сохранённой квитанции. Девять
профильных случаев PASS. Подписи, область действия, запрет повторной
отправки, временное окно физических подтверждений и API v1 не менялись.

Полный pytest: 2866 PASS, 4 штатно пропущены. Полная локальная проверка
выпуска PASS, совместимость Android PASS, критическое покрытие 75% при
пороге 75%. Точный локальный комплект VERIFIED_LOCAL, без дрейфа.
Все 50 браузерных тестов PASS за 17.5 минуты: 735 действий, 43 исходные
точки управления, ошибок нет. Точная проверка сетевого отчёта PASS.
Все 980 исходных файлов и их права совпадают с проверенным комплектом.

Самостоятельное ревью Codex: производственное изменение ограничено
проверкой времени при подтверждении сохранённого режима. Frontend содержит
только точную замену версии кеша. Блокирующих замечаний в этой области нет.

Перед активацией подготовлены точная резервная копия 1.52.230 и защищённая
история климата. Нужны успешная проверка GitHub, публикация точного выпуска,
установка, проверка конфигурации и живая проверка режима после перезапуска.
Private Android 1.0.277 совместим и не требует повторной установки.

Ограничения: принятие физической команды не означает подтверждения точной
аппаратной цели. Прежняя ошибка стартовой миграции сценариев не исправляется
этим выпуском. Физическое открытие домофона не выполнялось.

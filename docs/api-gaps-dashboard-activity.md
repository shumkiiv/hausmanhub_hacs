# Невыполненный контракт активности главной

Версия наблюдения: 1.51.57.

HACS и Android ожидают в `GET /api/hausman_hub/v1/dashboard` массив `events` с
понятными пользователю последними событиями дома. Текущая реализация возвращает
пустой массив, поэтому карточка «Последняя активность» корректно показывает
пустое состояние, но не может быть информативной.

Для закрытия пробела API должен возвращать до четырёх последних событий:

- стабильный `id`;
- русское `title` без `entity_id` и внутренних кодов;
- короткий `message` с результатом действия или изменением состояния;
- `roomId`, если событие относится к комнате;
- `ts` в миллисекундах Unix.

Клиент уже обрабатывает отсутствие массива и не требует изменения backend в
этом релизе.

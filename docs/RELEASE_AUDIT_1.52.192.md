# Проверка выпуска 1.52.192

## Результат

Исправляющий выпуск разделяет ручной приоритет люстры и автоматическую работу
точек тамбура. Ручная люстра остаётся без автоматических изменений яркости и
температуры, а точки независимо следуют присутствию.

## Безопасность

- Частичный приоритет разрешён только системному сценарию
  `system-tambur-adaptive-controller`.
- Повторная проверка ручного состояния перед физической командой ограничена
  целевым светильником. Ручная люстра не блокирует точки, но ручное состояние
  самих точек по-прежнему защищено.
- Для остальных сценариев ручной свет блокирует всю автоматическую световую
  ветку, как и раньше.

## Сценарии приёмки

- Ручная люстра включена, присутствие обнаружено: параметры люстры пропущены с
  причиной `manual_light_already_on`, точки получают подтверждённую команду
  включения.
- Обычный профиль с взаимозаменяемыми источниками: ручной источник блокирует
  всю ветку.

## Проверено перед публикацией

- Полный release-gate: 1862 теста, 4 пропущены по отсутствию Home Assistant в
  локальной среде.
- Критическое покрытие: 230 тестов, суммарное покрытие выбранных модулей 76%.
- Браузерная проверка: 19 из 19 сценариев.
- Компиляция Python и проверка HACS-пакета завершились без ошибок.

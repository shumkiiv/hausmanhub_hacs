# Карточки устройств v2

Канонический компонент находится в Figma HMH II:
`25 • CANON — Devices` -> `CANON / Device Card v2 / 2026-08-12`.

Компонент `HausmanHub / Device Card v2` содержит варианты `Online`,
`Attention`, `Offline` и `Loading`. Он используется как общий визуальный
контракт для планшета и HACS.

## Иерархия

- Имя устройства: 20 px.
- Основное подтверждённое состояние: 24 px.
- Комната, тип и вспомогательные факты: не меньше 14 px.
- Статус связи виден на карточке, недоступность не маскируется.

## Взаимодействие

- Карточка открывает подробности устройства. У перехода нет отдельной
  визуальной кнопки «Открыть».
- Быстрое действие называет объект: «Выключить свет», «Закрыть шторы»,
  «Открыть замок». Абстрактные «Открыть», «Закрыть» и «Позиция» в карточке
  запрещены.
- В одной карточке допускается одно быстрое действие. Управление, требующее
  значения, остаётся в листе деталей.
- Нажимаемые области не меньше 48 px. Это относится к кнопкам, полям ввода
  и закрытию листа.

## Реализация HACS

Общий рендерер: `custom_components/hausman_hub/frontend/hausman-hub-device-card.js`.
Контекстные подписи команд формируются функцией
`contextualDeviceActionLabel`. Сценарный API сохраняет нейтральные названия
команд, чтобы не смешивать доменную модель с именем конкретного устройства.

# Базовый замер dashboard snapshot, 2026-08-14

## Решение

Conditional response и delta пока не добавляются. Текущий snapshot мал, чистая
проекция собирается заметно быстрее сетевого round-trip, а API сохраняет
защитный заголовок `Cache-Control: no-store`. Усложнение протокола сейчас не
даёт доказанного выигрыша.

После restart, разрыва SSE, gap или смены contract capability клиент по-прежнему
получает полный snapshot через `GET /api/hausman_hub/v1/dashboard`.

## Воспроизводимый замер

Команда:

```bash
python tools/measure_dashboard_snapshot.py --runs 1000
```

Контрольный замер representative-проекции: 1 000 сборок, median 0,171 мс,
p95 0,331 мс, максимум 0,714 мс, compact JSON 7 333 байта. Канонический golden
fixture занимает 6 556 байт. Числа зависят от машины, поэтому сравнивать нужно
порядок величин и повторять замер на том же runtime.

## Когда вернуться к оптимизации

Повторный design review нужен, если production-замер подтвердит хотя бы один
порог:

- p95 чистой сборки выше 10 мс;
- representative compact payload больше 64 КиБ;
- p95 полного локального HTTP-запроса выше 250 мс при исправном Home Assistant;
- сеть планшета регулярно передаёт неизменный snapshot и это видно в метриках.

Даже после превышения порога обязательным остаётся полный snapshot после gap,
restart и смены contract capability. Delta не становится единственным способом
восстановления состояния.

# Release audit HausmanHub 1.52.97

Дата: 2026-08-15.

## Причина и исправление

- Живая история состояний подтвердила повторяющиеся восстановления света
  `on -> unavailable -> unknown -> on`. Последний переход ошибочно совпадал с
  условием `Состояние равно Включено` и запускал закрытие штор.
- Триггер состояния теперь пропускает переходы, в которых старое или новое
  состояние отсутствует, равно `unknown` либо `unavailable`. Настоящее
  переключение `off -> on` осталось рабочим.
- Исполнитель не вызывает `cover.close_cover`, когда текущее состояние уже
  равно `closed` или `closing`. Открытая штора по-прежнему получает команду.
- Все три живых сценария штор оставлены выключенными. Их определения и
  настройки не менялись.

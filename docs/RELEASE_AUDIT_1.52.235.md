# Проверка Hausman for Home Assistant 1.52.235

`v1.52.235` сохраняет действие «Вернуть весь климат в авто» из 1.52.234.
Оно снимает только ручное владение текущего контура, не посылает физических
команд и не изменяет память других контуров. Точечный инкремент исправляет
подпись итогового браузерного отчёта, которая не совпала в первом облачном
прогоне 1.52.234.

Проверено до публикации:

- Локальный выпуск: 2324 unittest PASS, 4 skipped, 72 pytest PASS,
  critical coverage 75% и 50 browser tests PASS.
- GitHub Actions `34326173469` на `9642b28` PASS: серверные тесты, coverage,
  browser-gate и проверка provenance отчёта завершились успешно.
- Выпуск опубликован без assets. Он совместим с Contracts `0.65.2` и private
  Android `1.0.278` build `282`.

Установка в Home Assistant:

- Запрошены automatic backup и проверка конфигурации. Точная установка
  `v1.52.235` ответила HTTP 200; installed/latest стали `v1.52.235`.
- После одной команды restart соединение закрылось до HTTP-ответа, что
  соответствует началу перезапуска. Home Assistant затем восстановился;
  повторный `homeassistant.check_config` вернул HTTP 200.
- После restart climate runtime не поднялся: capabilities содержит
  `climate_runtime.available=false`, а два read-only запроса runtime вернули
  503 `unavailable`. Полный live smoke завершился BLOCKED. Физические
  климатические команды и действие возврата в авто не запускались.

Следующий шаг: отдельная read-only диагностика конфигурационного входа и
старта climate runtime. Не повторять установку, restart или климатическую
команду как попытку скрыть этот блокер.

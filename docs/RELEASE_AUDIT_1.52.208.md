# Проверка выпуска 1.52.208

## Что входит

Исправлена подтверждённая production-причина ошибки общей температуры.
Повторная проверка оставляла комнату в списке после удаления её единственного
ручного исполнителя. Пустая комната нарушала модель контура, а уже принятые
команды остальных комнат ошибочно превращались в общий отказ.

Теперь комната без исполнителя выбранной оси не входит в повторный физический
план. Её ручное или недоступное устройство остаётся в исходной надёжной
квитанции как отдельное безопасное исключение. Команды не повторяются,
неизвестный результат не объявляется подтверждённым. Контракты `0.64.3` и
Android API не менялись.
Выпускная provenance привязана к `1.52.208` и digest
`055deecd2dd281539f9a2da3c0ac488e6e402b1ad16db6299cfa15747cd1e610`.

## Проверено локально

- тест сначала воспроизвёл production `ContourViolation` на комнате только с
  нецелевым или исключённым исполнителем;
- после исправления повторный план содержит только комнаты с исполнителем
  выбранной оси;
- смешанные ручные, недоступные и автоматические владельцы сохраняют прежние
  безопасные квитанции;
- полный выпускной набор, coverage и browser-gate выполняются до публикации.

# Release audit HausmanHub 1.52.96

Дата: 2026-08-14.

## Область выпуска

- Ручное выключение настроенного кондиционера через общий device action API
  сначала сохраняет ручной режим конкретного устройства, затем отправляет
  физическую команду. Автоматический климатический tick больше не может сразу
  включить его обратно.
- При отклонённой команде или исключении до её принятия введённое этим запросом
  ручное исключение откатывается. Сценарии и сам климатический контур используют
  прежний путь и не создают ложный ручной режим.
- Dashboard и climate runtime публикуют единый режим с русскими подписями.
  Общая карточка, окно устройства и список оборудования климата показывают его
  компактной светлой меткой.
- Consumer pin обновлён до `hausmanhub-contracts 0.32.0` (`9e29af7`).

## Проверки выпуска

- Полный pytest: 1407 тестов пройдено, 4 пропущено, 926 subtests пройдено.
- Профильные тесты подтверждают порядок `manual -> turn_off`, откат при отказе,
  сохранение после restart, dashboard projection, русские подписи и frontend.
- `git diff --check` пройден. GitHub Actions `31835035051` завершён успешно.
- Release commit `34cf496`, tag и GitHub Release `v1.52.96` опубликованы.

## Production

- Перед установкой создан automatic backup `a8fe37bd`, 841,3 MB. Последний
  успешный automatic backup: `2026-08-14T19:55:16+00:00`, backup manager
  вернулся в `idle`.
- Config check принят до установки, после установки и после единственного
  restart. Installed и latest равны `v1.52.96`, frontend содержит 35 cache
  references версии `1.52.96`.
- Живой dashboard вернул 13 комнат, 85 устройств и 4 карточки кондиционеров с
  валидными русскими режимами. «Кондиционер кабинет» и «Кондиционер Алиса»
  были выключены и уже отображались в ручном режиме.
- Climate runtime после restart имеет `fresh: true`, phase `managed`, 5 комнат
  и публикует `mode_name` для каждого кондиционера.

Проверка production была read-only. Физические команды, климатические цели и
режимы устройств при деплое не менялись.

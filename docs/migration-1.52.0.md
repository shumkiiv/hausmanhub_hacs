# Обновление HausmanHub до 1.52.0

Версия 1.52.0 завершает перенос рабочего контура в Home Assistant. После
обновления панель и закрытое Android-приложение читают один dashboard snapshot,
а команды выполняются только опубликованными API HausmanHub HACS.

## Перед обновлением

1. Создайте резервную копию каталога `custom_components/hausman_hub` и настроек
   Home Assistant.
2. Не удаляйте старый Node-RED flow до проверки комнат, датчиков, исполнителей и
   целей климата в HausmanHub.
3. Убедитесь, что физические климатические устройства доступны в Home Assistant.

## Безопасный переход

1. Установите 1.52.0 через HACS и перезапустите Home Assistant.
2. Откройте «HausmanHub → Настройки → Диагностика» и проверьте связь, сохранённую
   конфигурацию, климатический контур, сценарии и энергию.
3. Проверьте каждую комнату в мастере без отправки команд, затем выполните пробную
   команду только для одного выбранного устройства.
4. Убедитесь, что `/api/hausman_hub/v1/capabilities` объявляет dashboard API v1,
   а `/api/hausman_hub/v1/dashboard` возвращает комнаты и устройства.
5. После стабильной работы отключите старую автоматику Node-RED. Хранить экспорт
   можно как архив, но рабочим источником истины остаётся Home Assistant.

## Откат

Если интеграция не загружается, восстановите резервную копию каталога компонента,
перезапустите Home Assistant и приложите обезличенную техническую сводку из
настроек HausmanHub. Откат не должен менять области, устройства и сущности Home
Assistant.

Android-приложение распространяется отдельно в закрытом репозитории. Его исходники,
APK, токены и снимки экрана запрещено прикладывать к публичному HACS-релизу.

# Проверка Hausman for Home Assistant 1.52.236

Этот выпуск возвращает доступность climate runtime после одной старой
проверенной смешанной операции общей цели. Загрузчик переводит только
ошибочный служебный статус `accepted_timeout` в `terminal_mixed` и лишь
после проверки подписи, квитанции, checkpoint и области действия. Повторной
команды приборам нет: запись по-прежнему распознаётся как duplicate.

Pin Contracts приведён к уже используемому `0.65.2` (`69fe733`). Проверяются
хэши трёх встроенных схем, поэтому номер версии и их фактическое содержимое
не расходятся.

Проверено до публикации:

- 420 профильных тестов PASS, 400 subtests PASS.
- Полный pytest: 2882 PASS, 4 штатно пропущены, 1293 subtests PASS.
- Полный local release: 2325 unittest и 72 pytest PASS; critical coverage
  75% при требуемом пороге 75%.
- Браузерная проверка: 50 PASS. Она проверила 43 исходные точки, 735
  сигнатур и 708 действий, без ошибок, непредусмотренных запросов и изменений
  живого дома.
- GitHub Actions `34341637755` на `cd59b79` PASS. Выпуск `v1.52.236`
  опубликован без assets.

Установка в Home Assistant:

- Автоматическая резервная копия и проверка конфигурации завершились HTTP 200.
- Точная установка `v1.52.236` завершилась HTTP 200; installed/latest
  подтверждены как `v1.52.236`. После одного restart Home Assistant
  восстановился.
- Read-only smoke PASS: все проверяемые маршруты вернули 200, climate runtime
  свежий, команды разрешены, активных операций нет. Самая долгая проверка
  заняла 178 мс. Физические команды не отправлялись.

Ограничение безопасности: первый отменённый запрос резервной копии кратко
содержал административный заголовок в локально наблюдаемой командной строке.
Секрет не записывался в репозиторий или этот отчёт, а повторные запросы шли
через защищённую конфигурацию. Административный токен Home Assistant следует
ротировать отдельной авторизованной задачей.

## Проверка управления после установки

На Lenovo с Android `1.0.278` общая цель изменена с 25,0 на 25,5 °C через
обычный экран планшета. Она завершилась без активной операции, и пять
управляемых комнат сохранили 25,5 °C. Через HACS отдельно проверены спальня,
кабинет и кухня, каждая операция также завершилась. Комнаты Игоря и Алисы
не имеют права на отдельную цель в текущей области управления, поэтому
защита не обходилась.

Свежий read-only smoke PASS: climate runtime 200, свежий снимок, активных
операций нет. Он подтверждает сохранение целей и завершение операций, но не
считает физическое подтверждение всех приборов полным.

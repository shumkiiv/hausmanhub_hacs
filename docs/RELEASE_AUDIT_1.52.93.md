# Release audit HausmanHub 1.52.93

Дата: 2026-08-14.

## Область выпуска

- Каталог сценариев публикует физическое устройство, комнату, тип и отдельные
  возможности Home Assistant. Несколько сущностей одного прибора больше не
  выглядят как разные устройства.
- Триггеры и условия используют только состояния выбранной возможности. Для
  датчика движения доступны `Движение` и `Нет движения`, при сохранении
  остаются исходные значения `on` и `off`.
- Выбор устройства вынесен в отдельное окно с поиском и быстрыми фильтрами по
  комнатам и типам. Фильтры можно применять одновременно.
- Consumer pin обновлен до `hausmanhub-contracts 0.31.0` (`ac54bf6`).

## Проверка до публикации

- Полный pytest: 1392 теста пройдено, 4 пропущено, 926 subtests пройдено.
- Локальный release-gate: 1390 тестов пройдено, 4 пропущено. Schema fixtures,
  Android compatibility, HACS package, product naming и file safety прошли.
- GitHub Actions `31794893988` завершен успешно.
- Release commit `3b8df4b`, tag и GitHub Release `v1.52.93` опубликованы.

## Production

- Перед установкой завершен automatic backup. Последний успешный снимок:
  `2026-08-14T11:13:29+00:00`, backup manager вернулся в `idle`.
- Config check принят до установки, после установки и после единственного
  restart.
- HACS установила явную версию `v1.52.93`. Installed, latest и frontend cache
  marker равны `1.52.93`, новые JS и CSS окна выбора доступны.
- Живой каталог содержит 454 наблюдаемые и управляемые сущности. Датчик
  `binary_sensor.0xf044d3fffebaf11b_occupancy` имеет одну возможность
  `Движение` и два состояния: `Движение`, `Нет движения`.
- Сущности освещения и `Do not disturb` люстры малого коридора имеют один
  `physical_id`, а пользователю показаны возможности `Освещение` и
  `Не беспокоить`.
- После restart в system log есть две одиночные warning-записи существующего
  климатического shadow/trial с `ClimateRuntimeUnavailable`, count каждой
  равен 1. Ошибок сценариев и новой версии нет.

Физические команды, сценарии и климатические цели не отправлялись.

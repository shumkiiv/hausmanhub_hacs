# Проверка выпуска 1.52.207

## Что входит

Добавлена безопасная диагностика ошибки, которая остаётся после исправления
`1.52.206` на живой системе. Если сбой возникает после отправки климатических
команд, журнал Home Assistant получает только класс исключения и стек вызовов.
Запись не содержит request ID, entity ID, адресов, токенов или параметров
команды.

Поведение квитанции не ослаблено. Неизвестный результат остаётся
неповторяемым, не считается подтверждённым и не запускает автоматический
повтор. Контракты `0.64.3` и Android API не менялись.
Выпускная provenance привязана к `1.52.207` и digest
`634f0470ea62ea5a1ebd33264e317e15ec55a9bca5bc28a053942865d6252c6f`.

## Проверено локально

- профильные тесты климатической квитанции и запрет подтверждения по старому
  снимку;
- стандартный выпускной набор, coverage и browser-gate выполняются перед
  публикацией;
- живая диагностика выполняется только после backup, config check и restart.

Ручной и автоматический режимы подтверждаются по сохранённой настройке,
без ложного ожидания физического вызова. Уже подтверждённая часть операции
не меняет доказательство при позднем чтении нового состояния устройства.

Старая противоречивая квитанция восстанавливается только после проверки
подлинности состояния, отдельной операции и области. Снимается только
недоказанный успех. Цель и принятые команды сохраняются, повтор запрещён.
API v1 и физические защиты не ослаблены. Frontend содержит только смену
версии кеша, что проверено побайтовым сравнением с предыдущим выпуском.

PASS, совместимость Android PASS; критическое покрытие 75% при пороге 75%.

неизменяемость доказательства и восстановление, включая отклонение подделки.
Все 13 native-записей живой системы проходят новый загрузчик без изменения.

история. Нужны публикация точного выпуска, проверка конфигурации и
успешная загрузка истории после одного restart.

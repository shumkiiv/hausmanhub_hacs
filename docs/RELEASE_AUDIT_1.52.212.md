# Проверка выпуска 1.52.212

## Что исправлено

Версия 1.52.212 сохраняет защиту светового профиля после подтверждённого
ручного выключения и устраняет ошибку запуска, найденную при установке
1.52.211. Собственный обработчик `OPTIONS` конфликтовал со штатным CORS
Home Assistant и не позволял загрузить интеграцию. Теперь preflight полностью
обрабатывает HTTP-сервер Home Assistant, а прикладные методы API не меняются.

После обнаружения ошибки production сразу возвращён на рабочую 1.52.210.
Перед первой установкой создана полная резервная копия `1373edeb` в локальном
хранилище и на KeeneticSSD. Android `1.0.273` build `277` не меняется и не
требует отдельного релиза.

## Проверки выпуска

- Регрессионный тест запрещает прикладным представлениям повторно объявлять
  `OPTIONS`, которым владеет CORS Home Assistant.
- Полный локальный выпускной набор прошёл 2071 тест и 4 пропуска. Контрактные
  проверки, упаковка, границы публикации и безопасность файлов зелёные.
- Chromium завершил 16 тестов полного обхода: проверены 735 из 735 элементов,
  708 безопасно нажаты, 27 опасных действий намеренно заблокированы. Нет
  пропусков, ошибок, незаписанных команд, внешних обращений или утечки мутаций.
- Выпускная provenance привязана к `1.52.212` и digest
  `80445d5f9421cf7d7e917eefc934e6799934ac9496cbca3d656d6b372bd69486`.

## Откат

При проблеме установить `v1.52.210` и перезапустить Home Assistant либо
восстановить полную резервную копию `1373edeb`.

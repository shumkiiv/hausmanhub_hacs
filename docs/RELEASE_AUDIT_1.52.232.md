# Проверка Hausman for Home Assistant 1.52.232

Совместная цель температуры и влажности больше не требует увлажнителя
в каждой комнате. Температурные приборы и увлажнители выбираются отдельно,
ручные исключения сохраняются при проверке результата и не получают команд.
Состав запроса фиксируется по проверенным исполнителям. Промежуточный
расчёт автоматики не может незаметно удалить из него комнату.

Устаревшая влажность не мешает температурному прибору только при отдельном
доказательстве свежей температуры. Общая оценка комнаты остаётся прежней.
Неизвестная свежесть, старые нужные показания, повреждённые привязки и полное
отсутствие запрошенного типа исполнителя по-прежнему отклоняются.

Проверено:

- Десять новых регрессий: смешанные пять комнат, ручные приборы, точная
  пара 25.5 °C и 45%, восстановление после перезапуска и отсутствие повторов.
- Полный pytest: 2876 PASS, 4 штатно пропущены. Полный local release PASS.
- Критическое покрытие: 75% при пороге 75%, проверка пройдена.
- Браузер: 50 PASS. Точный отчёт подтверждает 735 состояний элементов,
  708 действий и 43 исходные точки; непредусмотренных запросов и ошибок нет.
- Комплект VERIFIED_LOCAL: все 981 файл и их права совпадают с исходниками.
- Самостоятельное ревью Codex: область команды, ручное владение,
  доказательства свежести, строгие отказы и совместимость API v1.

Повтор на прочитанных настройках дома выполнялся только с имитатором
приборов. Он сохраняет обе цели и возвращает отдельные ручные и отложенные
результаты. Этот повтор не является проверкой живого HTTP или оборудования.

Contracts 0.65.0 и private Android 1.0.277 совместимы, их код не менялся.
Frontend содержит только точную замену номера кеша. Перед установкой
подтверждены полный backup текущего дня и свежие защищённые архивы
компонента и климатической истории на самом сервере.

Публикация требует успешной проверки точного коммита в GitHub. Установка,
проверка конфигурации, restart и приёмка общей цели с планшета фиксируются
корневым проектом после выполнения. Прежняя блокировка миграции сценариев
не исправляется этим выпуском. Устройства не включаются ради проверки.

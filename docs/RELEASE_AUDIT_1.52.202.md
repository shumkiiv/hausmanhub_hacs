# Проверка выпуска 1.52.202

## Что входит

Выпуск исправляет доступ к `GET /api/hausman_hub/v1/capabilities`: локальный
администратор Home Assistant получает тот же read-only снимок возможностей
климата, что и локальный планшет. Это единственная production-правка: GET
использует уже существующую общую проверку климатического контура.

Внешний администратор и локальный обычный пользователь по-прежнему получают
`403`. Строгий путь без query-параметров сохраняет `404`, ответ содержит
`Cache-Control: no-store`. Права всех POST-маршрутов и планшетных-only
контуров не менялись.

Полный QA-отчёт связан с SHA-256
`99f2c84e7949c2a2b0ad78681220c991b43988eff17bc3f79970763b16c9b5a9` точного
состава frontend-файлов, browser harness и реестра контролов.

## Проверено локально

- матрица доступа к capabilities: планшет и локальный администратор `200`,
  равный payload и `no-store`; внешний администратор и обычный пользователь
  `403`; query-вариант `404`;
- полный HACS browser harness: 703 из 703 действий, без пропусков, ошибок,
  внешней сети и выхода за безопасный контур;
- проверка provenance и целевой серверный набор: 156 тестов, 246 subtests;
- полный серверный набор HACS завершён без сохранённых падений.

## Safety denylist

Не выполнять команд для автоматов, кранов воды, замков, охраны, сирен,
отопления, кондиционеров, света, штор, ворот, бытовой техники или любого
другого физического устройства. Для этого выпуска допустимы только проверка
интерфейса, конфигурации и чтение состояния.

## Что входит

Общая климатическая цель сохраняет известные, статически корректные
недоступные автоматические устройства как отложенные. Для них не отправляется
команда в Home Assistant, а квитанция содержит точный результат 0/0. Устройство
в ручном управлении сохраняется тем же безопасным способом, без смены режима.

Доступные владельцы по-прежнему получают только свои точные вызовы. Смешанный
результат завершается как частичный после чтения состояния доступных владельцев,
без повторной попытки для отложенных или ручных. Контракты 0.64.3 не менялись.

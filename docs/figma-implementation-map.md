Дата аудита: 2026-08-01.

## Источник истины

- Figma: `HMH HA`
- File key: `UK1PgZUQQrvYJ7tRZzWyvo`
- Базовая ширина макетов: 1440 px
- Канонический планшетный интерфейс: `HMH II`, file key
  `4vaAkBsKwtSyqJrr2X5RRs`, 2560 × 1600 px
- Код панели: `custom_components/hausman_hub/frontend/hausman-hub-panel.js`
- Технология: нативный Web Component с Shadow DOM, JavaScript и CSS

Figma задаёт визуальную структуру. Android и HACS реализуют один продуктовый
каркас, а различие ширины меняет только адаптивную раскладку. Действующий код и
API задают поведение и данные. Перенос макетов не меняет REST-маршруты, форматы
payload, хранение или исполнение команд.

## Общий каркас

Канонический каркас повторяется на рабочих экранах:

1. поле страницы `#EEF1F6` / `#0B0F14`, максимальная ширина 1440 px;
2. постоянная левая навигация с маркой HausmanHub и версией;
3. заголовок, контекстный подзаголовок и системное состояние;
4. заголовок текущего подраздела и короткое описание;
5. секции-карточки шириной контента с радиусом 20 px;
6. шаг отступов 8/12/16/20/24/32 px и шрифт Inter.

Основная навигация одинакова на планшете и в HMH HA: `Главная`, `Освещение`,
`Климат`, `Комнаты`, `Медиа`, `Безопасность`, `Устройства`, `Энергия`,
`Сценарии`, `Настройки`. Старое правило о четырёх вкладках отменено как источник
расхождения между Android, Figma и HACS.

## Порядок переноса

1. Токены, фон страницы, шапка, статус и единая продуктовая навигация.
2. Экран помощника AI `91:576`, включая сетку формы, статистику и советы.
3. Обзор и климатические подразделы.
4. Сценарии и настройки.
5. Мастер настройки и карточки устройств.
6. Визуальные регрессионные снимки и адаптивная доводка.

## Критерии приёмки экрана

- Визуальная иерархия и порядок секций совпадают с соответствующим фреймом.
- Цвета, радиусы, тени, размеры текста и отступы берутся из токенов.
- Все существующие интерактивные элементы сохраняют действие и доступность.
- Есть состояния загрузки, ошибки, пустых данных, dirty и disabled.
- На ширинах 1024 и 640 px нет горизонтального переполнения, обрезанного текста
  и перекрытия элементов.
- Светлая и тёмная темы структурно идентичны.
- Unit/contract-тесты панели проходят, а снимки проверены визуально.

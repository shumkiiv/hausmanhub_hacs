# Проверка выпуска 1.52.214

## Что исправлено

Версия 1.52.214 восстанавливает применение общей целевой температуры. Работающие
термостаты получают цель сразу, а выключенные кондиционеры больше не получают
команду, которую их интеграция принимает только на несколько секунд и затем
отменяет. Для них цель сохраняется и применяется после включения.

Смешанная операция завершается после индивидуальной проверки устройств и не
ждёт полного окна подтверждения из-за заведомо отложенных исполнителей.
Принятая Home Assistant команда сохраняется до возврата ответа, поэтому
перезапуск не превращает её в ложный результат 0/0. Исправлена и загрузка
смешанного результата после таймаута.

Android `1.0.273` по-прежнему считает правдивый смешанный результат ошибкой,
хотя общая цель уже сохранена, работающие устройства подтверждены, а
выключенные ожидают включения. Для корректного сообщения пользователю нужен
отдельный выпуск Android после согласования поведения клиента.

- Итоговая цель всех комнат равна 25,5 °C, незавершённых операций нет.
- После установки точного релиза повторное сохранение 25,5 °C завершилось за

восстановить полную резервную копию `b6344afe`.

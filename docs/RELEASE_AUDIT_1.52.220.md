# Hausman Hub HACS 1.52.220: совместимость discovery Home Assistant 2026.9

Дата подготовки: 2026-09-05.

## Причина выпуска

Home Assistant 2026.9 возвращает для device-trigger пять полей идентичности и
дополнительное пустое поле `metadata`. Сравнение всего ответа как словаря
ошибочно блокировало запуск управляемых переключателей.

## Исправление

- Разрешены только пять неизменных полей идентичности либо те же поля с
  единственным `metadata: {}`.
- Непустое, неправильного типа или дополнительное поле, пропущенная или
  изменённая идентичность блокируют запуск.
- После полной проверки всех шести триггеров attach получает очищенную локальную
  конфигурацию. До этого ни один обработчик не подключается.
- Отказ журналируется фиксированными `code` и `reason` без payload,
  идентификаторов устройств, тем и секретов.

## Границы кандидата

- Манифесты первой и второй фаз миграции, источники управляемых сценариев и их
  ревизии не изменялись.
- Физические команды и проверки реальных устройств не выполняются.

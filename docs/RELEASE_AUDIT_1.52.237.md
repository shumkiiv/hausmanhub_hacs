# Проверка Hausman for Home Assistant 1.52.237

Выпуск возвращает комнату из ручного климатического режима полностью: при
выборе `automatic` очищаются сохранённые ручные отметки всех настроенных
приборов именно этой комнаты. Поэтому она не остаётся формально
автоматической с недоступной персональной температурой. Другие комнаты,
приборы и ручные исключения не меняются. Операция режима изменяет только
память владения и не посылает физических команд.

Проверено до публикации:

- TDD-регрессия: RED-GREEN для очистки отметок комнаты, подтверждённого
  режима и отсутствия вызовов исполнителя.
- Полный pytest: 2883 PASS, 4 штатно пропущены, 1293 subtests PASS.
- Полный local release: 2326 unittest, 4 штатно пропущены и 72 pytest PASS.
- Critical coverage: 75% при пороге 75%.
- Browser gate: 50 PASS. Проверены 43 исходные точки, 735 сигнатур,
  708 безопасно выполненных и 27 намеренно заблокированных действий, без
  внешней сети и изменений живого дома.
- GitHub Actions `34352266387` PASS на `4599516`. Выпуск `v1.52.237`
  опубликован без assets.

Установка в Home Assistant:

- Перед установкой запрошена автоматическая резервная копия. Её запуск не
  создавал повторный запрос, пока выполнялась операция.
- Штатный `update.install` применил строго `v1.52.237`; installed/latest
  подтверждены как `v1.52.237`.
- Проверка конфигурации принята. После одного restart Home Assistant
  восстановился на `2026.9.1`.
- Первый read-only запрос во время прогрева получил 404 на capabilities.
  Повторная проверка условия сразу получила 200, без повторной установки.
  Итоговый smoke PASS: climate runtime свежий, команды разрешены, активных
  операций нет, максимум 303 мс.

После установки по явному поручению владельца две точные операции
`set_room_mode=automatic` вернули комнаты Игоря и Алисы в полный контур.
Control revision изменился с 26 до 28. У обеих комнат есть
`set_room_target`; у комнаты Игоря доступна также влажностная цель. Активных
операций нет. Физическое подтверждение каждого прибора отдельно не
заявляется: операция режима не является командой прибору.

# Hausman Hub HACS 1.52.217: аудит исправления выпускного контроля

Дата подготовки: 2026-09-05.

## Причина выпуска

Версия 1.52.216 была отозвана до установки. Обязательная проверка критического
покрытия выполнила 260 тестов и остановила выпуск на 74 процентах при пороге
75 процентов. Отдельный запуск модуля проверки сценариев старта завершался с
результатом `Ran 0 tests`: семь синхронных функций не обнаруживались стандартным
загрузчиком `unittest`.

## Исправление

- Модуль проверок старта предоставляет стандартному загрузчику семь обёрток
  `FunctionTestCase`, по одной для каждой существующей синхронной проверки.
- Модуль включён в обязательный набор критического покрытия.
- Порог 75 процентов и список проверяемых производственных модулей сохранены.
- Производственная логика, контракты, сценарии и семантика миграции не менялись.

## Проверка кандидата

- Отдельный модуль запуска: 7 тестов.
- Обязательный контур критического покрытия: 267 тестов, 76 процентов при
  неизменном минимуме 75 процентов.
- Проверки версии, ресурсов панели и происхождения тестового снимка выполняются
  для 1.52.217.

## Границы кандидата

- Физические проверки устройств в подготовку кандидата не входят.
- Публикация, установка и живая проверка выполняются только после независимых
  этапов проверки и отдельного решения корневого координатора.
- Исторические записи и аудит версий 1.52.215 и 1.52.216 сохранены без
  переписывания.

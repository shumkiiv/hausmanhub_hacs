# HausmanHub 1.52.104: безопасный доступ с нового компьютера

## Что получит пользователь

В разделе «Система» появилась карточка «Безопасный доступ с нового
компьютера». Она открывает или копирует HTTPS-адрес текущего Home Assistant,
поэтому пользователю не нужно вспоминать старый небезопасный адрес.

Рядом с карточкой и в отдельном руководстве описаны три действия: проверить
отпечаток публичного корневого сертификата, установить его в хранилище Windows
текущего пользователя и перезапустить браузер. Инструкция не содержит адреса
конкретного дома, IP-адреса, ключей или снимков настроек.

## Границы безопасности

- HTTP не включается и проверка TLS не ослабляется.
- Панель не скачивает и не устанавливает сертификаты автоматически.
- Пользователь импортирует только публичный `.cer` или `.crt` после сверки
  SHA-256 отпечатка, переданного владельцем дома отдельным каналом.
- Файлы закрытого ключа не принимаются и не упоминаются как пригодные для
  импорта.

## Проверка перед выпуском

- Статические контрактные проверки панели и руководство безопасного доступа
  проходят.
- Полный локальный release gate выполняется перед публикацией тега.
- Выпуск содержит только код и документацию HACS. APK, AAB и материалы
  отладки планшета в него не входят.

## Откат

Откатить интеграцию можно на предыдущую версию HACS. Уже добавленный
сертификат удаляется только вручную через `certmgr.msc` после сверки его имени
и отпечатка. Автоматического удаления доверенных центров нет.

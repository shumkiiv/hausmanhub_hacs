# Визуальная регрессия панели HausmanHub

`hausman-hub-panel-harness.html` загружает панель с фиксированными тестовыми
данными. Он нужен для проверки интерфейса без запущенного Home Assistant и без
изменения реальной конфигурации дома.

## Запуск

Из корня репозитория запустите статический сервер:

```bash
python -m http.server 8765
```

Базовый адрес:

```text
http://127.0.0.1:8765/tests/visual/hausman-hub-panel-harness.html
```

Поддерживаемые параметры:

- `section`: `overview`, `lighting`, `climate`, `rooms`, `media`, `security`,
  `devices`, `scenarios`, `settings`;
- `screen` для раздела климата: `contour`, `profiles`, `schedule`, `home`,
  `windows`, `assistant`;
- `settings` для раздела настроек: `overview`, `rooms`, `connection`,
  `appearance`, `system`;
- `theme`: `light` или `dark`.

Пример:

```text
http://127.0.0.1:8765/tests/visual/hausman-hub-panel-harness.html?section=climate&screen=profiles&theme=dark
```

## Критерии приёмки

- одновременно отображается только выбранный экран климатического раздела;
- на широком экране нет горизонтальной обрезки текста и элементов;
- на узком экране горизонтальная прокрутка допустима только в подменю климата;
- заголовки, значения, поля и кнопки не перекрываются и не выходят из карточек;
- светлая и тёмная темы сохраняют читаемый контраст и одинаковую иерархию;
- в пользовательских подписях нет необработанных идентификаторов API или
  строк вида `mdi:*`, кроме технических полей выбора сущностей;
- физическое устройство считается один раз, независимо от количества его
  функций и сущностей Home Assistant;
- интерфейс соответствует структуре экранов файла Figma `HMH HA`.
